# Aishwarya M | Technical Writer Portfolio

Personal portfolio and online resume of **Aishwarya M**, a technical writer based in Chennai, India.

**Live site:** https://mvaishwarya.github.io/

## About

I have over 6+ years of experience in documentation, communication, coordination and teaching, including more than 5 years as a technical writer in Shipping Logistics and Telecommunications. I write release notes, user guides, admin guides, installation guides and SOPs.

This site brings my resume, documentation samples and writing together in one place.

## Pages

| Page | File | What it shows |
|------|------|---------------|
| Home | `index.html` | Introduction, technical and soft skills, software knowledge |
| Resume | `resume.html` | Education, work experience, certifications and awards, LinkedIn recommendations |
| Portfolio | `portfolio.html` | Documentation samples (Android Auto user manual, Git and GitHub installation guide, Adobe Illustrator quick user guide, UI/UX redesign) |
| Blog | `blog.html` | Writing and blog posts |

## Built with

- HTML5 and CSS3
- Custom styles in `assets/css/live-resume.css`
- jQuery and the Bootstrap JavaScript bundle for the menu and interactions
- Google Fonts: **Sora** (headings) and **Instrument Sans** (body text)
- Font Awesome icons

The layout is responsive and works on desktop, tablet and mobile.
